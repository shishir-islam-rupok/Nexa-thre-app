# NEXA

NEXA is a social platform for messaging, communities, and payments.

## Local setup

Create a `.env` file from `.env.example` and add the URL and anon key from your Supabase project. Then run `npm run dev` and open the local URL shown in the terminal.

To view a production build, run `npm run build` followed by `npm run preview`. Do not open `dist/index.html` directly with `file://`.
